# 待实现细节（记录用，暂不实现）

## 商人 · 市籍许可的扩展

当前实现只有三条路径：交情（≥32 必定得籍）、名望（≥35 + 贽礼 300，需判定）、
告官立籍（城中无人可托时，费率 ×2 兜底）。

可再补的细节：

1. **许可可被撤销**
   - 触发：所在国国势跌破阈值、玩家与该国交恶、该国灭亡
   - 后果：市籍失效，商号停业（保留等级，重新领籍后可复业）

2. **限籍数量**
   - 一城商籍有限（如 5 个），先到先得
   - 满籍时须等他人退籍，或加价「顶替」
   - 制造同城竞争，避免玩家无脑占满 31 城

3. **许可可转让**
   - 与商人 NPC（弦高、范蠡）交易市籍
   - 价格随该城商号经营状况浮动

4. **名望路线的判定加入城池属性**
   - 大城吏治严，更难通融（临淄、洛邑 −10）
   - 小邑人少事简，反而好说话

5. **许可与国势挂钩**
   - 国势高 → 市租低（招徕商旅）
   - 国势低 → 市租高（官府急于敛财）

## 商人 · 其他

6. **商号经营风险**
   - 所在国战乱时月入减半
   - 伙计数量影响抗风险能力
   - 可能被人恶意收购

7. **盘下他人商号**
   - 城中已有 NPC 商号，出钱收购
   - 价格随经营状况浮动

8. **抵债所得 / 临终受赠**
   - 借出的钱还不上，以商号抵
   - 与某商人交情极高时，对方临终托付
