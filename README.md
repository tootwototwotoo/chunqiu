# 春秋 · 列国志

以中国春秋时期（前 722 — 前 473）为背景的 **HTML5 单机人生养成游戏**，玩法参照《太阁立志传 5》：
选择一个身份，在列国之间行走、修行、交友、出仕、经商、游说、讲学，用一生在乱世里留下名字。

纯原生实现：**无构建步骤、无框架、无外部素材**。界面为水墨风，地图、人物、小游戏全部由 CSS / SVG / Canvas 动态绘制。

---

## 快速开始

### 方式一：单文件版（最省事）

直接双击项目根目录的 **`chunqiu.html`** 即可游玩，无需服务器、无需联网。
它是把 CSS 与全部脚本打包内联后的版本（约 210 KB）。

### 方式二：源码模块版

```bash
npm start            # http://localhost:5173
```

浏览器打开 `http://localhost:5173`。

> **不要直接双击 `index.html`**：源码版使用 ES Modules，`file://` 协议下会被浏览器以 CORS 拦截，
> 表现为「页面只有顶栏、主区域一片空白」。请用 `npm start`，或改用 `chunqiu.html`。
> 若脚本未能启动，页面会在 2.5 秒后显示红色错误提示与原因。

修改源码后重新生成单文件版：

```bash
npm install          # 首次：安装 jsdom / esbuild（仅开发与测试用）
npm run build        # 输出 chunqiu.html
```

游戏进度保存在浏览器 `localStorage`：**每次行动后自动存档**（1 秒内合并写入），切出页面时补存，可在「存档」页开关或导出文本备份；存储不可用时也能正常游玩，只是无法存档。

每逢游戏日期进入新月份，自动保存一次（每月 30 天，并非现实时间计时）。标题「继续前缘」读取手动档和自动档中最近保存的有效档，损坏档会跳过；旧档没有保存时间时按游戏年月日比较。存档页的普通「读档」仍读取手动档，「读取自动存档」读取自动档，并显示其完整游戏年月日。保存失败会显示提示，建议立即导出文本备份。

## 玩法概览

### 时代与出身

开局可选 **五个年代**，不同年代的人物、国势与历史事件各不相同：

| 年代 | 年份 | 主题 |
|---|---|---|
| 王室东迁 | 前 722 | 郑庄公小霸，王纲解纽 |
| 桓公称霸 | 前 685 | 管仲相齐，尊王攘夷 |
| 晋楚争雄 | 前 640 | 城濮、邲、鄢陵，百年拉锯 |
| 弭兵之世 | 前 560 | 向戌弭兵，卿族渐强 |
| 吴越争雄 | 前 515 | 孙武、伍胥、勾践、范蠡 |

四种出身，各自有独立的成长闭环：

- **珍宝**：美玉、明珠、珊瑚树、犀角、象牙、玄璧六种，价 500~3600 金，愈贵愈罕见。
  一城仅一件、购后 30~90 日补货、每购一次天下同类涨价；可于本国朝堂「献宝于朝」换功勋与名声，
  玄璧留囊可使册命请封 +15%，集齐六种得「富可敌国」称号。
- **游侠**：演武、除害、从军；决斗以「斩克突、突克崩、崩克斩」相制，守可回气，绝招耗气。
- **商人**：三十一城物价各异，贱买贵卖；扩充商队、开设商号、打探行情。
- **说客**：三回合论辩。认同度初始 50，每轮从三项具体回应中选一：切中顾虑 +15、有道理 +5、回避 −10；
  思路合对方心性 +5、相悖 −5；每局可出示一次相关证据 +10（用错不消耗）。三轮后 ≥70 成功、40–69 妥协、<40 失败。
  心性（好利 / 重义 / 好名 / 慕强）固定，可在人物面板、城中列表和论辩界面看到；三回合中不会改变。
  50 个场景覆盖内政、邦交、军事、朝堂、商贸；妥协时有权限的对象会追加后续差事。
  证据需平时获取：**城中「查访线索」**（技艺判定，失败后该城冷却 1 日）、**人物面板「打听消息」**（交情 >20）、
  **市集「书肆」**（仅大城出售，500~700 金）；每件证据只有一种来源，
  按主题（粮草/水利/军务/刑律等）跨场景使用，人物界面单列「证据」栏。
- **学者**：设坛讲学收弟子、著书立说成一家、与名士论辩。

### 工程化

```bash
npm run lint    # ESLint 静态检查
npm test        # 全部测试（含数据一致性回归）
npm run check   # lint + test
npm run race    # 爵位竞速平衡模拟
```

界面测试分三层：`ui-smoke.mjs`（主流程）、`merchant-ui.mjs`（商人三期）、
`screens-ui.mjs`（名鉴 / 交游 / NPC 弹窗 / 四职业专属动作 / 存档页 / 舆图）。
每层都用 jsdom 走真实点击路径，而非直接调系统函数——「系统测试全绿但按钮点不开」
这类问题只能由此发现。

`test/consistency.mjs` 做跨文件语义校验，专门拦 lint 抓不到的错误：
职业 id 是否来自数据定义、货物/珍宝/特产/偏好是否互相对得上、
城池与道路是否连通、论辩证据是否落在有书肆的城、界面动作 id 是否真实存在等。

### 国君世系

国君按 `reign`（在位起止）判定，登基前不出现、退位或身故后消失：

- 全 19 国共 **229 位国君**，时间轴覆盖 **93.8%**（-722 ~ -473）
- 含周室 14 位天子、郑 9 位、卫 13 位、燕 10 位、吴 7 位、越 4 位等
- **史料缺载的年份**以「国名 + 爵位」为名兜底（如「晋侯」「楚王」），
  人物说明里注明「此君之名史籍失载，仅存国号与爵位」，仍可正常廷对。
  合成国君**只充当国君**：不进入 NPC 表、不套用公子/前国君三阶段、
  不参与差事发布与市籍授受，只出现在廷对里
- 在位以外的国君条目（公子、前国君）按普通人物对待：
  `effectiveRole` 决定界面称号与交互权限，`role` 字段仍保留真实身份
- 驾崩与继位是**大事件**：`systems/reign.js` 按年检测更替，生成带三选一的弹窗
- 只对「玩家所仕之国」与「国势最强之国」弹窗，其余只入纪事，避免刷屏
- 国势影响：旧君薨 −8、新君立 +3
- 交情规则：新君若与你旧识则交情保留；素未谋面则保持未识，不额外惩罚
- **三段身分**：国君在时间轴上依次是「公子 → 国君 → 前国君」
  - 及笄（15 岁）前不出现；及笄后、即位前以**公子**身份可见
  - 即位当年即为国君，**幼年继位者不受及笄限制**
  - 退位但未身故者为**前国君**，仍可拜访；身故后消失
  - 无生卒记载者按「即位前约 30 岁」推算生年，卒年取退位后 5~10 年（由 id 派生，读档不变）

## 问政：女性角色的专属价值

史书里的这些女性多以「判断力」著称——邓曼谏楚武王、敬姜论劳逸、
许穆夫人赋《载驰》、怀嬴「秦晋匹也」。故她们的专长不是技艺，而是看局势。

    条件：交情 ≥20，消耗半日 · 6 力，20 日冷却
    效果：按专长揭示一条隐藏情报，名声 +1

| 专长 | 揭示内容 |
|---|---|
| 内政 `court` | 所仕之国（未仕则所在国）的真实国势数值 |
| 邦交 `diplo` | 当前交兵之国，或「四境无事」 |
| 军略 `army` | 最强与最弱之国及其国势 |
| 人心 `people` | 本地可结交之人；本地无人则荐别国贤者 |

## 代码约定：清单只保留一份正本

同一份枚举/清单不得在多处重写，否则会「改了定义、行为不改」。
以下为全库唯一正本，别处一律引用：

| 清单 | 正本 | 辅助函数 |
|---|---|---|
| 可出仕职业 | `defs.CAREER_PROFESSIONS` | `isCareerProfession()` |
| 官阶名 | `defs.RANKS[].name` | `state.rankName()` |
| 技艺→属性 | `defs.SKILL_STAT` | `statOfSkill()` |
| 技艺门类（武/文/市） | `defs.SKILL_DEFS[].cat` | — |
| 事件效果类型 | `events.EFFECT_TYPES` | `isEffectType()` |
| 事件类别 | `events.EVENT_KINDS` | `isEventKind()` / `eventKindLabel()` |
| 心性四值 | `debates.TAGS` / `OPPOSITE` | — |
| 城池标签 | `world.CITIES[].tags` 取值表 | — |

`test/consistency.mjs` 会静态扫描源码，一旦有人重新手抄这些清单即失败。

## 代码约定：数据字段必须有消费方

项目已四次出现「数据写了但没人读」的问题（`LOCAL_NOTABLES`、
`PERMIT.trialBonus`、`voices.intro`、季隗的开场白）——数据齐全、运行不报错，
只是永远不生效。

`test/field-usage.mjs` 会从各数据模块抽出实际存在的字段名，再到非 data
源码里找有没有读取痕迹（`.field` / `?.field` / `'field'`），找不到即失败。

已知豁免写在 `ALLOW` 里，每条须注明理由：
- 存档字段（由 `state.js` 的 `fill` / `defaults` 统一补齐校验）
- NPC 静态描述字段（界面统一渲染）
- 技艺 id（通过 `SKILL_DEFS` 遍历）
- 字典项内与键同名的 `id`（字典由 `Object.values()` 消费）

`test/dead-code.mjs` 则查「导出函数有没有调用方」：剥掉定义行后统计引用，
生产与测试都为 0 即死代码。被 `import * as X` 整份引入的模块不检查
（调用写作 `X.fn()`，字面量里不会出现函数名）。

两个检查互补：前者防「数据没人读」，后者防「函数没人调」。

`test/data-integrity.mjs` 查数据之间的引用关系，分三组：

| 组 | 内容 | 是否阻断 |
|---|---|---|
| A 孤立引用 | id 指向不存在的实体（NPC.city、证据 npcId、效果 state…） | 阻断 |
| B 语义一致性 | city 与 state 是否相符、国君是否在朝堂城、生卒是否颠倒 | 阻断 |
| C 时间轴空档 | 某国某年无史载国君 | 仅提示 |

C 组只报告不失败：史料确有缺载年份（如许国 -722 无君），
`audienceRuler` 会以「国名 + 爵位」合成国君兜底，不影响游玩。

### 地图标记

舆图上可显示三类标记，并可在右上角「⚙ 标记」下拉中逐项开关：

- **差事目标**：三角旗，挂在目标城右上方；剩余 ≤3 日时旗子摆动（与当前城的呼吸圆环刻意区分：
  圆环是半径扩散、2.4 秒缓；旗子是绕杆摇摆、1.1 秒急）
- **商号**：实心方块，等级用尺寸区分（小肆 7 / 大铺 9 / 总号 11）
- **市籍**：空心圆环（已领籍但未开店时）
- **在途货运**：赭石虚线，沿法线偏移 2.5px 与差事路线平行不重叠；
  用 dashoffset 流动动画表示走向，不用起终点箭头
- **时事要地**：近 30 日内触发的历史事件所在地，暗金单环 1.6 秒扩散
  （与当前城的朱红双环刻意区分）；`where.state` 时标该国人口最大的城
- **交战之国**：交战国城池加暗红细环（0.9px）。仅视觉，不影响通行或贸易；
  战争状态由历史事件的 `war` / `peace` 效果产生（城濮、殽、吴入郢、夫椒、越灭吴）
- 另有：本国疆域、国名水印、道路三个图层开关

商号与市籍仅商人可见，献金求仕转职后不再显示。选中城池时，右侧会列出该城的差事、商号或市籍。

### 商人系统

商人无仕途，另有一条与五等爵平行的势力路径：

- **六阶**：贩夫 → 行商 → 坐贾 → 巨商 → 商盟之主 → 陶朱公
  后两阶要事功：商盟之主须与一国结盟，陶朱公须累计散财并曾持有巨资
- **商号三档**：小肆 800/月入 120、大铺 2000/320、总号 5000/800，约 6~7 个月回本
- **伙计**：300 金雇一名，月支 8、月入 +30，每号可雇 1~3 名
- **散财三途**：赈济（名声+国势）、助军（国势+盟国名声）、修路（本号月入）
- **献金求仕**：巨商可献 20000 金转职为士人，旧商号转为养廉保留三成进项
- 商人初始体力上限 120（车马之利）；运货差事改为预算制，买得越便宜赚得越多
- **市籍许可**：开号须先领市籍。向城中君相求取（交情 ≥32 必定得籍），
  或以名望（≥35 + 贽礼）说动，城中无人时可赴市亭告官立籍（费率双倍）
- **城池差异**：设肆成本与月入按人口浮动，回本月数一致
- **商盟（质誓）**：与一国结盟，盟国牙钱 +6%、商号月入 ×1.5；
  须月缴军资（国势×倍率），多盟者倍率按 2^(n-1) 递增，欠缴两月解盟，国亡盟绝
- **运输系统**：徒步/独轮车/牛车/马车/舟船，载重 24→800；
  坐贾以上须成批交割（最小量随阶次）、装运与在途都耗时，长途有遇劫风险，可雇护卫
- **水路**：21 城有 `water` 标记，舟船只通水路城
- **分庭抗礼**：商盟之主可以商贾之身见君，三回合议「议价 / 借粮 / 通商」，
  复用廷对认同度框架（起始 45~65，需 ≥70）；成则降牙钱、得粮秣或促通商
- **散财节制**：同类义举 90 日冷却，每城每年限两次
- 商人阶次现在按「历史峰值金钱」判定，花钱办事不会掉阶

平衡基线（`npm run race:merchant`）：陶朱公中位 21.1 年，三条路线通关率均 100%

### 代码加固

`test/hardening.mjs` 覆盖审核发现的问题，防回归：

- 商人无仕途：`canTakeOffice` 为唯一闸门，朝堂谒见、廷对、举荐、`seekOffice` 四条路径全封
- serve.cjs：畸形 URL 返回 400 而非崩溃；路径判断带分隔符
- 随机事件冷却以「日」为单位（30 日）
- 所有设限期的差事都会逾期，不再只有出行类
- 修习小游戏使用存档内种子随机，可复现
- 时间基准统一为 `util.absDay`，全项目唯一

### 平衡性基准：爵位竞速

`npm run race`（全量 9600 局）或 `npm run race:quick` 会模拟三类可仕职业在不同策略与技巧下的爵位进程，
统计通关率、中位耗时与卡点，并对照合格标准。报告示例见 `docs/peerage-race-report.md`。

模拟器只调用真实系统函数，Bot 遵守全部成本（体力、金钱、时限、冷却）；小游戏表现由「玩家技巧档位」注入。

| 档位 | 目标 |
|---|---|
| 公爵中位耗时 | 12~20 年 |
| 最快 10% | 不少于 6 年 |
| 最慢 10% | 不超过 35 年 |
| 职业间中位耗时比 | ≤ 1.6 |
| 勤勉通关率 | ≥ 70% |
| 慢玩通关率 | ≥ 30% |

### 核心循环

```
城中行事 → 耗时耗力 → 修习/接差事/交易/交游 → 名声与技艺提升
      ↓                                        ↓
   舆图远行 ←──────── 差事限期 ←──── 谒见国君、出仕晋升
```

- **时间**：一切行动消耗日数；月初结算俸禄、商号进项、物价波动，并触发历史与随机事件。
- **体力 / 健康**：远行与修行耗体力，体力透支伤身；住店可恢复。
- **名声**：接差事、决斗、游说、讲学皆可增长；名声是出仕与结交的门槛。
- **出仕**：名声 ≥ 20、完成至少 3 件差事，往有「朝廷」的都城「谒见国君」接受三回合廷对。
  题库 24 题 + 8 条追问，每题切中 +15 / 有道理 +7 / 回避 −5，思路合国君心性 +5、相悖 −5；
  起始认同由政略、辩才、名声提升；认同 ≥70 方得任用，成功按功勋授士/中士/上士，失败需等十日；
  也可与卿相结好至交情 50，请其「举荐」直接入仕。商人无仕途。
- **官阶**：士 → 中士 → 上士 → 大夫 → 中大夫 → 上大夫 → 卿 → 执政，每月初按功勋擢升一级并按官阶领月俸；
  布衣时所积功勋不会作废，出仕时据以授官（最高上士），改仕他国则减半、从士做起。
- **五等爵**：男 → 子 → 伯 → 侯 → 公，由周天子册命，与官阶相互独立。官阶至卿/执政、功勋与名声达标后，
  可往洛邑领受**册命之试**：每级三道专属试炼（围捕/折冲/治邑/军略/定礼），完成后方可请封。
  请封按评价计算成算，未准则退半礼、名声小损并另命新试；五次未准后第六次必成。受封后获得食邑月入并计入结局。
  列国国君亦各有其爵（宋公、齐侯、郑伯、楚子、许男…）。
- **技艺**：八种技艺（剑术、射术、兵法、辩才、权谋、商贾、算术、学问），十级为满。
  八种技艺各有专属修习小游戏：剑术三连斩、射术移动靶、兵法阵法、辩才应对、权谋识破、商贾估价、算术心算、学问典籍配对；
  修习经验较早期版本减半，在校场、学宫、市肆修习可得「地利」（经验 +2）。
- **交游**：交谈、赠礼、问学、切磋、论辩。交情 25 可请教学艺，52 为知己，75 为挚友。
  赠礼每 10 日一次、最多把交情送到 75；举荐需交情 75 且名声 20。
- **珍玉**：全国最多八块，仅洛邑、新郑、临淄、曲阜、郢、雍、绛、陶有售；一城一块，购后 30 日补货，
  每购一次全局玉价上涨 15%（初始 500 金）；玉不能在市集普通买卖。
  人物初次相见即录入「名鉴」，共 42 位春秋名人，生卒年与所在地随年代变化。
- **历史**：26 个历史事件（繻葛、长勺、葵丘、城濮、邲、弭兵、柏举、夫椒、越灭吴……）按年月触发，
  可选择参与，改变名声、功勋乃至列国国势与城邑归属。
- **结局**：寿终或隐退时，按身份与成就给出评价（一国之相、天下名侠、陶朱之富、天下辩士、一代宗师……）。

## 白屏排查

1. **优先访问 `http://127.0.0.1:5173/`**（而不是只试 `localhost`），并 `Ctrl+F5` 强制刷新。
2. 正常启动时终端应输出两行监听：
   ```
   监听 IPv4  0.0.0.0:5173
   监听 IPv6  :::5173
   ```
   若只有 IPv6，浏览器走 IPv4 时可能连到别的服务或直接拒绝。
3. 端口被占用时换端口：`node serve.cjs 5174`。
4. 不想折腾服务器：直接双击 **`chunqiu.html`**。
5. 仍然空白时按 `F12` 看 Console 报错，页面也会在 2.5 秒后给出红色提示。
6. 若报错来自 `index.html` 中不存在的行号或陌生标识符（如 `LA is not defined`），
   通常是浏览器扩展注入或 IPv4 端口被其他程序占用所致，与游戏代码无关。

## 扩展指南

### 加一座城 / 一个人

- 城：在 `js/data/world.js` 的 `CITIES` 增加条目，并在 `ROADS` 增加连线（天数即行程）。
  物价需求在 `js/data/goods.js` 的 `DEMAND_BASE` 配置。
- 人：在 `js/data/npcs.js` 增加条目。`birth` / `death` 为负的公元前年份，`bias` 决定游说突破口，
  `teach` 为可传授技艺，`pref` 为偏爱礼物。无需改代码，出生年与在世判定自动生效。

### 加一个历史事件

在 `js/data/events.js` 的 `TIMELINE` 中追加：

```js
{ id: 'unique_id', year: -656, month: 7, title: '召陵之盟', body: '……',
  effects: [{ t: 'power', s: 'qi', v: 4 }],        // 无论玩家是否参与都会发生的天下大势
  choices: [
    { label: '为诸侯执笔盟辞', hint: '学问或辩才',
      check: { k: 'xuewen', dc: 48 },               // 判定：属性/技艺 + 随机
      success: [{ t: 'fame', v: 8 }, { t: 'money', v: 60 }],
      fail: [{ t: 'fame', v: 2 }],
      text: '……' },
  ] }
```

支持的效果类型：`money` `fame` `merit` `stat` `skill` `skillxp` `rel` `power` `owner`
`flag` `stamina` `health` `card` `goods` `duel`（见 `js/systems/events.js`）。

### 加一类差事

在 `js/systems/quests.js` 的 `TEMPLATES` 增加生成函数，并把类型加入 `KIND_BY_PROF`。
`mode` 为 `travel`（需出行完成）、`combat`（决斗）、`debate`（辩论）或 `check`（技艺判定）。

## 设计取舍

- **疆域用 Voronoi 自动生成**：以 31 座城为种子划分势力范围，按所属国上色（20% 透明），
  国界虚线；玩家所仕之国高亮为 32%；城池易主时按 `world.owner` 自动重绘。
- **地图不做实时军团战**：战争以「国势 + 从军判定 + 历史事件改城」表现，把复杂度留给个人养成与人际。
- **无美术资源**：全部以 CSS 渐变、SVG 河流/道路、文字角色与朱印构图，保证离线可运行、体积为零。
- **数值可复现**：随机数走存档内的 LCG，同一天命（seed）可重现同一局。
- **官阶与爵位分开**：士→执政是官阶（对应卿大夫士），男→公是五等爵。史实中五等爵多为诸侯之封，
  本作把「周室衰微、以功册命」作为演绎，允许玩家累进封爵并获得食邑月入。
- **可继续扩展**：家臣团、流派与师承、联姻、城下町经营、合纵连横外交网、多代继承。
